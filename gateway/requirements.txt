# Gateway RUNTIME deps (design: stdlib + fastapi + uvicorn + python-multipart only — no ORM, no
# pydantic-settings, no extra deps). These floors match the versions installed + tested into the
# ausmt conda env, which is the environment the suite is run in.
#
# THESE FLOORS ARE NOT WHAT SHIPS. requirements-lock.txt beside this file is the exact linux/amd64
# CPython 3.12 closure resolved from these floors, and deploy/docker/gateway.Dockerfile installs THAT.
# This file is the human-readable statement of intent; the lock is the reproducible artifact. Raising
# a floor here does nothing to the image until the lock is refreshed, and the refresh ritual lives in
# the lock's own header. Keep the two in step: refresh the lock in the same commit as a floor bump.
#
# python-multipart is required by starlette to parse multipart/form-data uploads; without it the
# form parser raises at import. uvicorn is the ASGI server the container entrypoint runs. httpx is
# NOT here — it is test-only (see requirements-dev.txt).
#
# starlette is FastAPI's ASGI toolkit (always installed with it); pinned explicitly because
# gateway/upload.py imports starlette.formparsers.MultiPartParser DIRECTLY to run the parser over a
# byte-capped stream (bounded multipart intake, fix #5 — see that module's header). It is therefore
# a first-class dependency here, not merely transitive.

uvicorn>=0.50
