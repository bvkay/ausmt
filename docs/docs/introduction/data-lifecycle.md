# Data Lifecycle

Where a dataset goes, from the field to somebody else's reuse. Each stage links to the page that owns it.

```text
Field Acquisition -> Time Series -> Transfer Functions -> Survey Package
  -> Validation -> Review -> Publication -> Discovery -> Reuse
```

**Field acquisition.** Station locations, dates, instrumentation, sensor orientations, deployment
notes: routine at the time, and often decisive when the survey is revisited.

**Time series.** The raw electric and magnetic field recordings.
[AusMT does not hold them](../interoperability/external-archives.md); the survey package records a
persistent identifier pointing at them.

**Transfer functions.** The processed frequency-domain products, and the core of what AusMT manages.
See [Transfer functions](../science/transfer-functions.md).

**Survey package.** Transfer functions organised with their metadata, provenance and citation
information into the unit AusMT publishes. See [Survey package](../data-model/survey-package.md).

**Validation.** Automated structural and metadata checks producing `PASS`, `WARNING` or `FAIL`. See
[Submission](../operations/submission.md).

**Review.** The judgements automation cannot make: ownership, licensing, embargo, collection
membership, provenance adequacy. See [Review](../operations/review.md).

**Publication.** The package enters the curated record. See
[Publication](../operations/publication.md). Derived products are generated by the next build, not
stored in the package; see [Science products](../science/science-products.md).

**Discovery.** Users search by region, collection, survey, organisation, time period or product. See
[How AusMT serves data](../interoperability/api-overview.md).

**Reuse.** New interpretations of old surveys, integration with newer ones, regional studies,
exploration, methodological work, student projects.

The lifecycle does not stop at publication. Metadata improve, provenance is recovered, publications
appear, and derived products are regenerated by better methods. Those changes go through
[versioning](../data-model/versioning.md) so the record of what was published, and when, stays intact.
